# UK Train Rides Analytics: Delays, Cancellations, Refunds and Revenue Forecasting (Power BI)

## Description
Analysis of 31,653 UK railway ticket transactions to find why delays, cancellations and refunds hurt revenue, with an interactive Power BI dashboard that turns the findings into actions.
